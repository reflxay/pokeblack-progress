# Website fonts

- `korataki-bold.woff2` is the supplied `korataki_bold.otf` converted to WOFF2.
- `pokemon-bw-text.woff2` is the supplied Pokémon Black, White, Black 2 and White 2 text font. Its internal CFF PostScript name is normalized to ASCII for compatibility. The outlines and original font metadata are preserved, including the FontStruct Non-Commercial License notice.

Both fonts are loaded locally with `@font-face`; no external font service is required.
