03 / THE PROJECT

Readable source.

pokeblack is a matching decompilation of Pokémon Black for Nintendo DS. The goal is to replace assembly with understandable C while rebuilding the original US ROM byte for byte.

The ROM already matches. Decompilation measures how much of its tracked code has been rewritten in C; these are separate milestones.

How the numbers are calculated

Code progress uses objdiff v3.8.0 function-sized code bytes from linked ARM9, autoload, and overlay objects. Embedded literal pools can be included in assembly code ranges. Discarded linker helpers, data-only regions, ARM7, and game assets are excluded from this code percentage.

Function totals combine emitted named assembly function labels with emitted C functions. Compiler-generated assembly wrappers are excluded, and inline assembly does not count as matching C. Assembly function sizes are shown as a dash because their labels do not provide reliable byte sizes.

Each snapshot identifies the verified main commit. The private repo's GitHub Actions rebuilds ARM9 and ARM7 and checks their recorded hashes before updating this site. The full ROM was verified before that commit reached main.
